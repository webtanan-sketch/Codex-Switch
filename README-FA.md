# مدیریت حساب‌های Codex

برنامهٔ محلی ویندوز برای نگهداری چند حساب ChatGPT/Codex، تعویض حساب مورد استفاده در VS Code و بازکردن محیط مستقل برای هر حساب.

**وضعیت: پیش‌نمایش توسعه، نسخهٔ ۰٫۱٫۱.** نصب‌کنندهٔ امضاشده و نسخهٔ عمومی هنوز منتشر نشده‌اند. اجرای موفق تست‌های کد به معنی تایید سناریوهای واقعی حساب‌ها روی ویندوز نیست. [گزارش اعتبارسنجی](docs/VALIDATION.md) را بخوانید.

[راهنمای کامل انگلیسی](README.md) · [معماری](docs/ARCHITECTURE.md) · [بازیابی](docs/RECOVERY.md) · [امنیت](SECURITY.md)

## روش استفاده

۱. برنامه و افزونهٔ همراه VS Code را از خروجی بررسی‌شدهٔ پروژه نصب کنید.

۲. در «تنظیمات»، مسیرهای `Code.exe` و باینری اصلی `codex.exe` را بررسی کنید.

۳. در صورت نیاز، ذخیرهٔ فایل‌محور احراز هویت را با دکمهٔ مربوط فعال کنید. پیش از تغییر `config.toml` نسخهٔ پشتیبان ساخته می‌شود. این کار اطلاعات ورود را از Keyring خارج نمی‌کند؛ ممکن است یک بار ورود مجدد لازم باشد.

۴. در «افزودن حساب»، نام دلخواه بنویسید و «وارد کردن حساب فعلی» را بزنید.

۵. برای حساب بعدی «ورود با ChatGPT» را انتخاب و ورود رسمی Codex را در مرورگر تکمیل کنید؛ سپس «ذخیرهٔ حساب» را بزنید. ورود جدید در مسیر جدا انجام می‌شود.

۶. در صفحهٔ حساب‌ها، «تعویض حساب» را بزنید. افزونهٔ همراه، میزبان افزونه‌ها و در صورت نیاز پنجرهٔ VS Code را تازه می‌کند. کارهای جاری را پیش از تعویض ذخیره کنید.

۷. برای کار هم‌زمان با حساب‌های متفاوت، «بازکردن VS Code» را انتخاب کنید. افزونهٔ رسمی Codex و افزونهٔ همراه باید در هر محیط مستقل نصب شوند.

## نکات کاربردی

در بخش «محدودیت مصرف حساب فعال»، درصد باقی‌مانده، طول بازه و زمان بازنشانی را می‌بینید. بازهٔ ساعتی یا هفتگی مطابق پاسخ Codex نمایش داده می‌شود؛ اگر سرویس اطلاعاتی ندهد، برنامه مقدار حدسی نشان نمی‌دهد. اطلاعات هر پنج دقیقه تازه می‌شود و دکمهٔ تازه‌سازی نیز پس از یک دقیقه در دسترس است.

این اطلاعات از رابط رسمی Codex و فقط برای حساب فعال خوانده می‌شود. برای این بررسی، درخواست هوش مصنوعی، ورود، خروج یا تعویض حساب اجرا نمی‌شود. به‌روزرسانی معمول اعتبارنامه، در صورت نیاز، بر عهدهٔ خود Codex است.

اگر ذخیرهٔ فایل‌محور فعال نباشد، دکمهٔ «تعویض حساب» ابتدا نام حساب مقصد و توضیح تغییر را نشان می‌دهد. با تایید «فعال‌سازی و تعویض حساب»، از تنظیمات نسخهٔ پشتیبان ساخته می‌شود و سپس تعویض انجام می‌گیرد.

- رابط فارسی و راست‌به‌چپ است؛ تاریخ‌ها شمسی و مسیرها چپ‌به‌راست نمایش داده می‌شوند.
- نسخهٔ فعلی برای Windows ۱۰/۱۱ x۶۴ و VS Code محلی طراحی شده است.
- اطلاعات ورود حساب‌های ذخیره‌شده با DPAPI حساب کاربری ویندوز رمزگذاری می‌شوند.
- فایل ورود فعال و مسیرهای اجرای مستقل، طبق نیاز Codex، فایل متنی دارند؛ پوشه‌های ساخته‌شده محدودیت دسترسی دارند.
- هیچ اطلاعات ورودی به سرور، آمارگیری یا افزونهٔ همراه ارسال نمی‌شود. خود Codex برای ورود و استفاده به اینترنت نیاز دارد.
- حساب ویندوز دیگر یا نصب دوبارهٔ ویندوز ممکن است نتواند فایل‌های DPAPI را بازیابی کند؛ این فایل‌ها خروجی قابل انتقال حساب نیستند.
- مسیر `maintenance/v1` ابزار قدیمی محل حساب‌ها فرض نمی‌شود. برای انتقال، هر حساب را در ابزار قدیمی فعال و سپس حساب فعلی را اینجا وارد کنید.
- سیاست احراز هویت سازمانی دور زده نمی‌شود.
- بستن پنجره، برنامه را در سینی ویندوز نگه می‌دارد؛ برای پایان کامل از «Exit / خروج» استفاده کنید.

## ساخت از سورس

نیازمندی‌ها: Node.js ۲۲+، Rust پایدار، ابزار C++ ویژوال استودیو و WebView۲.

```powershell
git clone https://github.com/webtanan-sketch/Codex-Switch.git
cd Codex-Switch
npm ci
cargo test --workspace --exclude codex-account-manager
npm run typecheck
npm test
npm run desktop:dev
```

ساخت خروجی:

```powershell
npm run desktop:build
npm run extension:package
```

نصب‌کننده در `target/release/bundle/nsis` و افزونهٔ `.vsix` در `apps/vscode-extension` ساخته می‌شود. خروجی‌های پیش‌نمایش امضای دیجیتال ندارند. وضعیت تست ویندوز، محدودیت‌ها و کارهای باقی‌مانده در مستندات انگلیسی شفاف درج می‌شوند.

مجوز: [Apache ۲.۰](LICENSE). این پروژه محصول مستقل وب‌تنان است و محصول رسمی OpenAI یا Microsoft نیست.
