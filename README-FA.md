# مدیریت حساب‌های Codex در ویندوز

با این برنامه می‌توانید حساب‌های ChatGPT/Codex خود را نگه‌داری کنید، حساب فعال را تغییر دهید یا برای هر حساب یک محیط جداگانهٔ VS Code باز کنید.

**پیش‌نمایش نسخهٔ ۰٫۱٫۲ برای Windows نسخهٔ `x64` منتشر شده است.** این نسخه امضای دیجیتال ندارد و هنوز تعویض واقعی بین دو حساب به‌طور کامل اعتبارسنجی نشده است. پیش از نصب، محدودیت‌ها و هش فایل‌ها را در صفحهٔ انتشار بخوانید.

## قابلیت‌ها

- ذخیرهٔ چند حساب و تعویض حساب فعال Codex با تأیید کاربر.
- بازکردن محیط‌های جداگانهٔ VS Code با مسیر داده و `CODEX_HOME` مستقل برای هر حساب.
- نمایش بازه و زمان بازنشانی محدودیت مصرف حساب فعال، مطابق اطلاعاتی که Codex ارائه می‌کند.
- رمزگذاری اطلاعات حساب‌های ذخیره‌شده با DPAPI ویندوز.
- رابط فارسی راست‌به‌چپ، تاریخ شمسی و راهنمای بازیابی محلی.

این برنامه دسترسی یا اشتراک Codex فراهم نمی‌کند و سهمیهٔ بیشتری ایجاد نمی‌کند. هر حساب باید متعلق به خود کاربر باشد و ورود به Codex طبق روش رسمی آن انجام می‌شود.

## نصب و شروع کار

۱. [نصب‌کنندهٔ نسخهٔ ۰٫۱٫۲](https://github.com/webtanan-sketch/Codex-Switch/releases/download/v0.1.2/codex-account-manager-0.1.2-x64-setup.exe) را دریافت و اجرا کنید. این نسخه برای Windows 10/11 نسخهٔ ۶۴ بیتی است و برای نصب به دسترسی سرپرست نیاز ندارد.

۲. برنامه را باز کنید و در بخش «تنظیمات»، مسیرهای VS Code و Codex CLI (`Code.exe` و `codex.exe`) را بررسی کنید.

۳. اگر Codex از روش ذخیره‌سازی `keyring` یا `auto` استفاده می‌کند، فقط در صورت نیاز گزینهٔ ذخیره‌سازی فایل‌محور را در خود برنامه فعال کنید. پیش از تغییر `config.toml` نسخهٔ پشتیبان ساخته می‌شود؛ این کار اطلاعات ورود را از Keyring استخراج نمی‌کند و ممکن است لازم باشد دوباره وارد Codex شوید.

۴. در بخش «افزودن حساب»، نام دلخواهی بنویسید و «وارد کردن حساب فعلی» را انتخاب کنید. برای افزودن حساب دیگر، «ورود با ChatGPT» را بزنید، ورود رسمی Codex را در مرورگر کامل کنید و سپس حساب را ذخیره کنید.

۵. برای تغییر حساب فعال، به صفحهٔ حساب‌ها بروید و «تعویض حساب» را بزنید. پیش از تعویض، کارهای جاری خود را ذخیره کنید.

۶. برای کار هم‌زمان با چند حساب، «بازکردن VS Code» را انتخاب کنید. در اولین اجرا، برای نصب افزونهٔ رسمی Codex در محیط جدید باید به VS Code Marketplace دسترسی داشته باشید.

## محدودیت مصرف و حریم خصوصی

برنامه بازهٔ ساعتی یا هفتگی و زمان بازنشانی را برای حساب فعال، مطابق پاسخ Codex، نمایش می‌دهد. اطلاعات هر پنج دقیقه به‌روز می‌شود و دکمهٔ به‌روزرسانی پس از یک دقیقه دوباره در دسترس است. اگر Codex اطلاعاتی ندهد، برنامه مقداری حدس نمی‌زند. برای دیدن این اطلاعات، حساب دیگری فعال نمی‌شود.

اطلاعات حساب‌های ذخیره‌شده با DPAPI حساب ویندوز رمزگذاری می‌شوند. فایل ورود حساب فعال برای استفادهٔ خود Codex روی رایانه باقی می‌ماند. این برنامه سرور ابری، آمارگیری یا ارسال اطلاعات ورود ندارد؛ خود Codex برای ورود و استفاده به اینترنت نیاز دارد.

## وضعیت این پیش‌نمایش

خروجی‌های نسخهٔ پیش‌نمایش امضای دیجیتال ندارند و Windows SmartScreen ممکن است دربارهٔ ناشناخته‌بودن ناشر هشدار دهد. هش `SHA-256` فایل‌ها در [صفحهٔ نسخهٔ ۰٫۱٫۲](https://github.com/webtanan-sketch/Codex-Switch/releases/tag/v0.1.2) درج شده است.

تست‌های خودکار پروژه اجرا شده‌اند، اما تعویض کامل و واقعی بین دو حساب هنوز تأیید نشده است. پیش از استفاده از حساب‌های مهم، [گزارش اعتبارسنجی](docs/VALIDATION.md) و [سناریوهای پذیرش](tests/ACCEPTANCE.md) را بخوانید.

## ساخت از سورس

نیازمندی‌ها: Node.js ۲۲ یا بالاتر، Rust پایدار، ابزارهای C++ ویژوال استودیو و `WebView2`.

```powershell
git clone https://github.com/webtanan-sketch/Codex-Switch.git
cd Codex-Switch
npm ci
cargo test --workspace --exclude codex-account-manager
npm run typecheck
npm test
npm run desktop:build
npm run extension:package
```

نصب‌کننده در `target/release/bundle/nsis` و افزونهٔ VS Code با پسوند `.vsix` در `apps/vscode-extension` ساخته می‌شود. راهنمای جزئی‌تر ساخت ویندوز در [BUILD-WINDOWS.md](docs/BUILD-WINDOWS.md) آمده است.
