  • برنامه سرویس ابری، آمارگیری یا ارسال داده ندارد.
  • فایل ورود فعال در قالب موردنیاز Codex روی دستگاه می‌ماند.

ENGLISH

One independent workspace for each Codex account.

A local Windows app to save accounts, switch the active Codex login, or open a separate VS Code environment for each profile.

Switch with consent. When file-based credential storage must be enabled, the app backs up Codex settings and asks before changing them.

Keep editor environments separate. Each profile has its own Codex home and VS Code user data. The official Codex extension is provisioned in that environment; initial Marketplace access is required.

Read active-account usage. Quota windows and reset times come from Codex. The app does not activate other saved profiles to query them.

Download Windows installer Download standalone EXE

Windows 10/11 x64, VS Code, and Codex CLI are required. Preview build; binaries are unsigned. Real two-account switching is not fully validated. Source and documentation.
