# انتشار نسخهٔ ۰٫۱٫۲ برای ویندوز

نسخهٔ پیش‌نمایش Codex Account Manager برای Windows 10/11 نسخهٔ ۶۴ بیتی منتشر شد.

## دریافت فایل‌ها

- [دانلود نصب‌کنندهٔ ویندوز](https://github.com/webtanan-sketch/Codex-Switch/releases/download/v0.1.2/codex-account-manager-0.1.2-x64-setup.exe)
- [دانلود فایل اجرایی مستقل](https://github.com/webtanan-sketch/Codex-Switch/releases/download/v0.1.2/codex-account-manager-0.1.2.exe)
- [مشاهدهٔ هش SHA-256 فایل‌ها](https://github.com/webtanan-sketch/Codex-Switch/releases/download/v0.1.2/SHA256SUMS-0.1.2.txt)

پیش از اجرا، هش فایل دریافت‌شده را با فایل `SHA256SUMS-0.1.2.txt` مقایسه کنید. فایل‌ها امضای دیجیتال ندارند؛ ممکن است Windows SmartScreen دربارهٔ ناشناخته‌بودن ناشر هشدار دهد.

## تغییرات

- رفع بازشدن پنجره‌های مستقل VS Code و آماده‌سازی افزونهٔ رسمی Codex در محیط هر حساب.
- نمایش بازهٔ محدودیت مصرف و زمان بازنشانی برای حساب فعال.
- بهبود فرایند تعویض حساب و بازپخش درخواست‌های افزونه پس از تازه‌سازی میزبان VS Code.

## پیش‌نمایش و اعتبارسنجی

این نسخه برای ارزیابی عمومی منتشر شده است؛ هنوز نسخهٔ پایدار یا امضاشده محسوب نمی‌شود. اجرای تست‌های خودکار موفق بوده، اما تعویض کامل و واقعی بین دو حساب در ویندوز به‌طور مستقل تأیید نشده است. پیش از استفاده از حساب‌های مهم، [گزارش اعتبارسنجی](https://github.com/webtanan-sketch/Codex-Switch/blob/main/docs/VALIDATION.md) و [سناریوهای پذیرش](https://github.com/webtanan-sketch/Codex-Switch/blob/main/tests/ACCEPTANCE.md) را بخوانید.

# Windows preview v0.1.2

Codex Account Manager preview for 64-bit Windows 10 and Windows 11 is available.

- [Download the Windows installer](https://github.com/webtanan-sketch/Codex-Switch/releases/download/v0.1.2/codex-account-manager-0.1.2-x64-setup.exe)
- [Download the standalone executable](https://github.com/webtanan-sketch/Codex-Switch/releases/download/v0.1.2/codex-account-manager-0.1.2.exe)
- [Verify SHA-256 checksums](https://github.com/webtanan-sketch/Codex-Switch/releases/download/v0.1.2/SHA256SUMS-0.1.2.txt)

Both executables are unsigned preview builds. Windows SmartScreen may warn that the publisher is unknown. Automated tests passed, but a complete real-world switch between two accounts has not been independently validated on Windows. Review the [validation report](https://github.com/webtanan-sketch/Codex-Switch/blob/main/docs/VALIDATION.md) before using important accounts.
