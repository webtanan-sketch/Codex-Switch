# Codex Account Manager 0.1.3

نسخهٔ کامل ۰٫۱٫۳ برای Windows x64 منتشر شد. این نسخه اصلاح بازشدن VS Code، صفحهٔ معرفی فارسی و بسته‌های نصب را به‌روز می‌کند.

## دریافت فایل‌ها

- [نصب‌کنندهٔ Windows x64](https://github.com/webtanan-sketch/Codex-Switch/releases/download/v0.1.3/codex-account-manager-0.1.3-x64-setup.exe)
- [برنامهٔ مستقل EXE](https://github.com/webtanan-sketch/Codex-Switch/releases/download/v0.1.3/codex-account-manager-0.1.3.exe)
- [افزونهٔ همراه VS Code](https://github.com/webtanan-sketch/Codex-Switch/releases/download/v0.1.3/codex-account-manager-0.1.3.vsix)

- [صفحهٔ معرفی برنامه](https://webtanan-sketch.github.io/Codex-Switch/)

## تغییرات

- دکمهٔ «بازکردن VS Code» اکنون پنجره را پیش از آماده‌سازی افزونه باز می‌کند. نصب افزونهٔ رسمی Codex در پس‌زمینه و به‌صورت best-effort انجام می‌شود؛ خطای Marketplace یا نصب افزونه جلوی بازشدن VS Code را نمی‌گیرد.
- نام فایل VSIX با نسخهٔ افزونه هماهنگ شد.
- صفحهٔ معرفی با فونت Vazirmatn خودمیزبان، پیوند مستقیم دریافت‌ها و توضیحات فارسی به‌روز شد.
- آزمون پذیرش دستی و آزمون‌های خودکار این نسخه توسط نگه‌دارنده تکمیل شده‌اند؛ وضعیت در [گزارش اعتبارسنجی](https://github.com/webtanan-sketch/Codex-Switch/blob/main/docs/VALIDATION.md) ثبت شده است.

فایل‌های اجرایی امضای دیجیتال ندارند؛ Windows SmartScreen ممکن است دربارهٔ ناشناخته‌بودن ناشر هشدار دهد. پیش از اجرا، هش فایل را با `SHA256SUMS-0.1.3.txt` مقایسه کنید.

# Codex Account Manager 0.1.3

The full Windows x64 release is available. This update fixes the Open VS Code flow and refreshes the Persian promotion page and release packages.

- [Windows x64 installer](https://github.com/webtanan-sketch/Codex-Switch/releases/download/v0.1.3/codex-account-manager-0.1.3-x64-setup.exe)
- [Standalone executable](https://github.com/webtanan-sketch/Codex-Switch/releases/download/v0.1.3/codex-account-manager-0.1.3.exe)
- [VS Code companion](https://github.com/webtanan-sketch/Codex-Switch/releases/download/v0.1.3/codex-account-manager-0.1.3.vsix)
- [SHA-256 checksums](https://github.com/webtanan-sketch/Codex-Switch/releases/download/v0.1.3/SHA256SUMS-0.1.3.txt)
- [Project page](https://webtanan-sketch.github.io/Codex-Switch/)

The manager now opens the requested VS Code window before attempting to install the official Codex extension in the background. Marketplace or extension-install failures do not prevent the editor from opening. The maintainer confirms manual acceptance and automated testing are complete; see the [validation record](https://github.com/webtanan-sketch/Codex-Switch/blob/main/docs/VALIDATION.md).

The Windows executables are unsigned, so SmartScreen may warn that the publisher is unknown. Verify downloaded files against the published SHA-256 manifest.
